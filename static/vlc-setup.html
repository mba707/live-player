Install the VLC opener

One-time setup on the computer that has Chrome and VLC. After this, Play opens VLC in one click.

1. Install

Same command on macOS and Linux. Do not use sudo. Do not double-click a downloaded file.

curl -fsSL http://localhost:8112/static/install-vlc-handler.sh | bash
Copied

The script detects the OS. On a Mac it builds ~/Applications/Live Player VLC.app. On Linux it registers a desktop handler. You should see Done and the path to the handler.

2. Restart Chrome

Fully quit Chrome, then reopen Live Player.

  • macOS: Cmd+Q. Closing the window is not enough.
  • Linux: Quit Chrome completely, or log out of the desktop session if the first Play click does nothing.

3. Click Play

Click ▶ on a live row. Chrome should ask to open Live Player VLC. Click Open. VLC starts on that stream via streamlink.

If Chrome never asks, run the curl command again and quit Chrome one more time.

Requirements

  • VLC already installed (Mac: /Applications/VLC.app).
  • This computer can reach the Live Player host.
