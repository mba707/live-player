Install the VLC opener

One-time setup on the computer that has Chrome and VLC. After this, Play opens VLC in one click.

1. Install

Pick your OS. Do not use admin/sudo. Do not double-click a downloaded file.

Run this in PowerShell (Windows key, type PowerShell, Enter):

powershell -ExecutionPolicy Bypass -Command "irm http://localhost:8112/static/install-vlc-handler.ps1 | iex"
Copied

The script finds VLC, writes %LOCALAPPDATA%\LivePlayer\live-player-open.cmd, and registers the liveplayer: protocol for your user. You should see Done.

Same command on macOS and Linux:

curl -fsSL http://localhost:8112/static/install-vlc-handler.sh | bash
Copied

On a Mac it builds ~/Applications/Live Player VLC.app. On Linux it registers a desktop handler. You should see Done and the path to the handler.

2. Restart Chrome

Fully quit Chrome, then reopen Live Player.

  • Windows: Menu → Exit, or right-click the Chrome tray/taskbar icon → Close / Exit. Closing the window is not enough if Chrome stays in the background.
  • macOS: Cmd+Q. Closing the window is not enough.
  • Linux: Quit Chrome completely, or log out of the desktop session if the first Play click does nothing.

3. Click Play

Click ▶ on a live row. Chrome should ask to open Live Player / Live Player VLC. Click Open. VLC starts on that stream via streamlink.

If Chrome never asks, run the install command again and quit Chrome one more time.

Requirements

  • VLC already installed (Windows: usually C:\Program Files\VideoLAN\VLC\vlc.exe; Mac: /Applications/VLC.app).
  • This computer can reach the Live Player host.
